# Proven layout patterns

Choose patterns by the page relationship. Use pptx_reference_library (action=search with pattern terms such as "大数字", "时间线", "对比") for optional lookup. Follow art-direction.md for key-page references and action=inspire.

| Pattern | Use it for | In a lesson | In a work report |
| --- | --- | --- | --- |
| **One big number + one line** (optionally over a minimal curve) | a single result that matters | a striking fact: "张骞出使历时 13 年" | the headline metric: "转化率 3.1% → 4.6%" |
| **Number progression with arrows** | change over time in 2–4 steps | then → now comparisons | before → after a launch |
| **KPI row** | one grouped result with comparable metrics | key figures read together | weekly metrics with no standout |
| **One statement, nothing else** (large type, one highlighted word, optional small illustration) | a problem, a question, a turning point | 想一想 / 讨论 questions | the one risk to escalate |
| **Headline left, picture right** (picture bleeds off the edge) | introducing a thing with evidence | an artefact, map or scene with its caption | a product screen with the change marked |
| **Same object, before and after** | showing a change | life before/after the Silk Road | old vs new flow (4 steps → 2) |
| **Proportional circles or bars** | sizes and shares | populations, distances, quantities | volumes, ticket counts |
| **Equation / formula of icons or words** | how parts combine | cause + cause = result | problem + fix = outcome |
| **Flow, cycle or hub diagram** | process, cycle, network | trade route, relay between merchants | a workflow or an incident timeline |
| **2×2 or Venn positioning** | where something sits among options | comparing two empires or routes | prioritising issues by impact and effort |
| **Side-by-side comparison with a verdict** | choosing between two | two sources or viewpoints | option A vs B, build vs buy |
| **Timeline with pinned callouts** | events in order | historical chronology | milestones, next week's plan |
| **People grid** (equal portraits, name + one line) | who is involved | historical figures | team and support needed |
| **Quote with portrait** | a voice or source | a primary-source quotation | user or customer feedback |
| **Section opener** (one big line on a full colour or with one illustration) | chapter breaks | lesson stages | report sections (only in long decks) |
| **Repeatable feature template** (same grid, new content) | a series of parallel items | parallel cases or regions | one slide per workstream |

Use one palette and type system. Follow art-direction.md for layout reuse and rhythm.

Build them natively: numbers and labels as editable text, circles and bars as native
shapes sized to the data, connectors for flows, real pictures for subjects. Never keep a
library slide's sample text or stock pictures; borrow the arrangement, or edit the
template itself with the deck's own content.
