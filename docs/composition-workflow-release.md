# Content-led composition release — 2026-10-09

Plugin: `0.1.0+codex.20261009composition2`. Existing contract v3 and new-task native
click requirement are unchanged. Default model remains gpt-6.1-sol / high.

## Changes and evidence

- Planning/authoring link the audience question, focus/proportions/reading path,
  enclosure meaning and native pacing to actual objects in the existing decisions.
  Sequential section checks reuse saved previews. No separate design gate, RAG,
  card ban, reference quota or fixed template rotation.
- Existing visual review checks dominant body-page repetition even when photos or
  covers interrupt it. Explicit visual requests are assessed alongside legibility;
  suggestions remain optional where no requirement/audience defect is demonstrated.
- native_canvas returns scoped handles and adds explicitly styled shapes, anchored
  connections, borderless semantic groups and handle-based native reveal steps.
  Missing/cross-page targets and reordering groups fail before writing. Text-fit
  errors report actual measured height/line count without shrinking.
- Two independent media imports overlap per task. Publication, provenance and
  task limits remain serialized; resumed imports retain checksum-verified files.
  The v2 no-network decoder returns allowlisted errors, including the 16 MP limit.
  An actual 5184×3456 fixture was rejected with the correct smaller-source advice.
- Rendering freezes input bytes in a host-private read-only mount and uses a
  private output mount. The PDF is validated and atomically published through
  no-follow task directory descriptors. Requested fonts, Fontconfig candidates,
  LibreOffice version and input SHA are recorded and sent to existing reviews.
  Runtime staging exposes the actual container font catalog. These diagnostics
  do not certify per-glyph fallback or actual PowerPoint playback.
- Existing state-preview collection now resolves relative output paths. A fresh
  four-page author encountered this issue; the fix has a regression check preserving
  source XML and requiring absolute render inputs.
- The website displays the resolved output language and its origin before submit.
  Manual selection wins; brief requests/script defaults are visible and editable.
  Script-majority inference applies only to creation; edit instruction language
  alone does not trigger an automatic translation.
  Only the resolved literal is saved. Existing task languages and quota are unchanged.
