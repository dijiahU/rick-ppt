## Behavior

- Removed mandatory design taxonomy/eligibility and categorical layout-diversity admission checks. Style, composition, visual form, audience strategy and palette remain author decisions; optional page descriptions are free text.
- Separated template-preservation declarations from design discovery. A specified paper or institutional template does not close permitted artistic/scientific visual exploration. Actual supplied-only/offline and faithful/scoped-edit boundaries still apply.
- Planning fixes explanation/evidence and a provisional direction. A single main author resolves the current page's wording, concrete detail and composition in presentation order, then inspects actual renders.
- Reference applications are recorded once; page associations and final slide notes are derived by the existing helper. Actual inspected work, truthful attribution and useful visible transfer remain necessary to claim influence.
- Retained page/order coverage, operation/source permissions, task-scoped asset paths, exact embedded bytes, illustrative generation boundaries, actual native behavior and final reference-note checks. Font defaults remain Times New Roman / SimSun with the existing exception/compatibility requirements. Single-file editable native delivery and bounded independent reviews are unchanged.
- Review reports distinguish technical validity/readability from design readiness, with concrete page/region findings. Artistic alternatives remain suggestions unless an explicit requirement or demonstrated comprehension/readability defect is involved.
