The `website/` directory mirrors the tracked source of published website v31,

## Included behavior

- The public form no longer offers API/local execution selection. The server
  chooses the admission backend from current worker capabilities. Administrators
  retain internal API pinning for model comparisons and execution audit details.
  Existing admissions keep their pinned backend on retry.
- The website includes the water/darkroom case gallery, editable scientific
  diagram and formula examples, attachment previews, administrator conversation
  access, and the 200 MB aggregate reference-upload limit.
- New presentations default to Times New Roman for Latin text and SimSun for
  Chinese, with genuine installed-font metrics and provenance. Native chart
  labels and axes support explicit Latin and East Asian font families. Font
  files and recipient availability are separate from PPTX font embedding.
- Animation authoring and the existing visual review inspect semantic click
  groups and reuse representative static state previews. Routine full-deck UI
  playback is not required; static simulation does not certify actual playback.
- Windows WPS guidance covers native connector endpoints, connection sites,
  grouping transforms and font portability. Actual Windows WPS playback has not
  been certified.
- The standalone skill and `releases/rick-pptx.zip` were rebuilt from current
  source.
