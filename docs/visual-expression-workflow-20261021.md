# Visual expression workflow update · 2026-10-21

Version: `0.1.0+codex.20261021visualbalance`.

A completed product-introduction deck showed a recurring production gap: abstract
capabilities and a worked scenario were still described in text columns and process
boxes, while concrete interfaces appeared only on the pages where observation was
strictly necessary. Different branch IDs had not ensured that the audience could
see useful outputs. Existing budget and permission diagrams remained effective.

## Adopted behavior

- Prefer meaningful imagery and visible examples where they communicate a subject,
  scene, change or result more directly than prose. Research actual visual assets
  alongside claims. Choose the subject and its explanatory role in the existing
  `role`/`visual_action`/asset routes before drafting body copy. Imagery is useful
  beyond narrowly indispensable documentary evidence.
- Worked cases show concrete inputs and outputs rather than only naming steps.
  Product frames, contextual photographs, original illustrations and native sample
  artifacts can combine with editable explanations and quantitative elements.
  Tiny decorative pictures beside unchanged paragraphs do not satisfy this aim.
- Select imagery for the content and brief; neither every page nor an unsuccessful
  search calls for a generated picture. Historical/documentary topics use authentic
  photographs and source documents. If optional imagery cannot be found, omit it
  and use sourced quotations, typography or editable analytical diagrams. Do not
  generate recreations of historical people/events/archival objects, even labeled
  illustrative. Explicitly required missing evidence stays a disclosed limitation.
- For suitable hypothetical scenes, concepts and proposed effects, generation is
  an option, directly or after unsuccessful search. Choose it for explanatory value,
  not to fill a picture-free page. Product introductions can use such illustrations
  while genuine interface/case evidence still needs genuine sources. Inspect/embed
  the actual selected files and preserve their illustrative identity and provenance.
- At the first normal render, the author checks whether the subject/result remains
  only an imagined object behind text. Show it and shorten the explanation it now
  carries. Preserve useful native charts, mechanisms, exact wording, conditions and
  editable analytical content. No picture quota or wholesale slide rasterization.
- Existing material preparation now explicitly includes actual visual assets, not
  just design inspiration. One author still makes pages sequentially. Existing
  visual review identifies concrete missed visual opportunities even if text-only
  comprehension is possible. Expression improvements are suggestions unless they
  address explicit requirements or demonstrated comprehension defects. No extra
  stage, automatic taste score or unbounded repair loop was introduced.

Changes are shared by local/API orchestration and aligned across the production
Skill, branch/reference guidance, portable overlay and generated installable Skill.
Scoped edits, supplied/offline constraints, honest documentary identity, native
click behavior and frozen historical artifacts retain their existing protections.
No task status or delivered presentation was changed.
