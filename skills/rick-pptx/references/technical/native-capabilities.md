# Native capabilities — HOW after selection

This is implementation routing, not an effect menu. Choose a treatment from the page content and [Visual review](../visual-review.md). Read this when a selected concept needs advanced native objects or motion; ordinary edits can use their direct technical references.

OOXML remains the implementation surface. Do not introduce a thick API, flatten slides or replace unknown markup because a helper lacks an effect. Test uncertain implementation on a small representative construction before propagation.

- Custom geometry and Bézier forms: inspect shape properties and path coordinate systems; start with [Slides and shapes](../slides-and-shapes.md) and [Groups](../groups.md). Preserve IDs and connector targets.
- Gradient text: retain editable runs and inspect run properties; use [Text](../text.md). Verify glyph contrast and actual rendering instead of rasterizing the title.
- Shadow, glow, reflection, gradients, bevel and extrusion: inspect relevant DrawingML properties, inherited theme values and existing effect/3D structures. Preserve schema order and namespaces; reuse known-working constructs only with understood dependencies. Validate and inspect a pilot at full resolution.
- Timing, motion paths and transitions: read [Animations](../animations.md); inspect target IDs, timing/build references and extension metadata. Morph needs compatible identity/metadata and application support; matching screenshots or a generic transition tag do not establish working Morph.
- Related parts: consult [Relationships](../relationships.md), [Images](../images.md), and [Safe mutation rules](../safe-mutation-rules.md) before dependency changes.

Encoding XML, structural validation, static rendering and verified playback are different evidence levels. Preserve native effects even when previews cannot fully display them; do not claim verification without relevant observation. Record application-specific uncertainty and retain a recoverable checkpoint. Follow [Research and visual assets](../research-and-assets.md) for sourcing and essential animation acceptance; this reference grants no additional tools or delivery exceptions.
