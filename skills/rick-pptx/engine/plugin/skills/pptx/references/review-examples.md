# Examples from the 68-deck review

Recognize the problem; do not prescribe one layout.

|Observed failure|Useful repair|
|---|---|
|A–F curves discussed but absent|Show actual labeled curves and comparison conditions|
|Hanoi code without rods/disks|Connect important states to code and preserve reasoning|
|Source visuals described in prose|Show the supplied example readably with use and source|
|Product tail repeats specifications|Group comparisons and connect specs to cases, conditions and evidence|
|One event's photo illustrates a different achievement|Restore identity/date or choose matching evidence|
|A long plan becomes strategic cards|Connect resources, timing, dependencies and intended outcomes|
|Different units/periods become equal number cards|Show comparable quantities, baseline, method and limits|
|Source conflicts become long audit paragraphs|Use a compact labeled comparison without invented resolution|

Automatic aesthetics scores miss some of these problems. Counts, colors and fixed
alternation do not measure understanding. Use audience needs and source scope.

## Communication and artistic-transfer calibration

| Observed pattern | What to inspect and repair |
| --- | --- |
| Many distinct form/layout labels, but the same pale filled boxes on most pages | Judge actual focus, scale, image/type relationships and reading tasks; choose a content-led canvas treatment rather than accepting category diversity as variety. |
| A real interface/case is introduced only through a feature map | Identify whether the audience must recognize/observe the real subject; show appropriate actual views with short editable annotations while retaining analytical relationships. |
| Artistic references affect a cover/palette but are claimed across every page | Compare the actual work, borrowed relationship and specified page action; do not accept generic "hierarchy" or artist names as proof. |
| Pure-text pages repeat the same paragraph panels | Edit redundant prose and design meaningful type scale, reading paths and whitespace; text itself can be the composition. |
| One accurate budget chart with direct units and a zero baseline | Preserve its quantity encoding. Improve wording/hierarchy as needed, without adding a decorative photograph to meet an image quota. |
| A source image is unavailable and the plan relabels a card as a diagram | Recheck the same audience question; a fallback label cannot replace missing necessary visual evidence. |

These are observed communication failures and a useful positive case, not a fixed
template set, artist corpus or required defect count. Explicit source-preserving
edits still judge fidelity and their authorized scope.
