# Website viewing mode

Select the task viewing branch and each page's behavior branch in decision-plan.json
using the plugin's references/workflow-branches.md. Behavior choices are static,
click_reveal, internal_navigation and embedded_playback, each with explicit entry
conditions and checks. Execute the selected branch; do not infer live/dual use from
a website task or require animation merely because a page has several ideas.
For click_reveal follow references/animations.md. Preserve explicit instructions
and unaffected existing behavior.

The website PNG/PDF previews are static. No PowerPoint slideshow player is exposed
to the isolated task. Inspect native timing and important states; clearly distinguish
these checks from untested real playback. Preserve the native builds in the download.
Do not claim playback verification from thumbnails or a successful export.
