这些文件用于展示不同任务的制作结果，不是所有任务必须套用的模板，也不代表所有版本已在 Windows WPS 或 PowerPoint 中完成实际放映验证。字体和播放效果仍受接收端环境影响。

图片复刻与原创设计已在表中区分；第三方作品、游戏、品牌和素材的署名保留在各自成品中。本次收录保留选定 PPTX 的原始字节。
