# 成品示例 / Presentation examples

这里收录 Rick 选择公开的 13 份独立 PPTX 成品，涵盖游戏宣发、技术演示、历史课件、海报和论文图复刻。点击文件后，可在 GitHub 文件页下载原始 PPTX。

| 文件 | 场景 | 页数 | 主要展示内容 |
| --- | --- | ---: | --- |
| [杀戮尖塔 2](slay-the-spire-2.pptx) | 游戏宣发 | 24 | 角色、游戏画面与长篇宣发叙事 |
| [数境](number-realm.pptx) | 游戏宣发 | 25 | 实机画面、角色素材与游戏机制讲解 |
| [麻醉机冷凝水管理](anesthesia-condensate.pptx) | 技术演示 | 8 | 设备照片、原理示意与技术方案比较；英文 |
| [毛选](mao-selected-works.pptx) | 历史课件 | 15 | 历史照片、原文引用与背景讲解 |
| [夜航爵士](night-flight-jazz.pptx) | 原创海报 | 1 | 爵士活动的图形、文字与版面设计 |
| [蒙特勒音乐节](montreux-jazz-festival.pptx) | 图片复刻 | 1 | 几何图形、纹理与文字的分层重建 |
| [昼醒咖啡](coffee-sale.pptx) | 电商海报 | 1 | 商品展示与促销信息编排 |
| [JBL GO 4](jbl-go4.pptx) | 电商海报 | 1 | 真实商品图片与可编辑文案组合 |
| [尼克斯 VS 76人](nba-highlights.pptx) | 视频封面 | 1 | 比赛图片与标题组合 |
| [万圣节派对](halloween-party.pptx) | 原创海报 | 1 | 主题氛围图与活动信息编排 |
| [DeepSeek-V3](deepseek-v3.pptx) | 论文图复刻 | 1 | MoE、MLA、公式与复杂连线 |
| [AlphaFold2](alphafold2.pptx) | 论文图复刻 | 1 | 多面板结构、几何示意与分子图片 |
| [AW-0 Framework](aw0-framework.pptx) | 论文图复刻 | 1 | 代码、视频帧、流程与符号组合 |

文字、图形和分析结构采用原生 PowerPoint 对象；照片、纹理及部分复杂视觉素材保留为独立图片。各案例的可编辑范围以文件中的实际对象为准。

这些文件用于展示不同任务的制作结果，不是所有任务必须套用的模板，也不代表所有版本已在 Windows WPS 或 PowerPoint 中完成实际放映验证。字体和播放效果仍受接收端环境影响。

图片复刻与原创设计已在表中区分；第三方作品、游戏、品牌和素材的署名保留在各自成品中。本次收录保留选定 PPTX 的原始字节。

原 CNN / YOLO 数值实验示例可在[替换前的历史版本](https://github.com/dijiahU/rick-ppt/tree/78cffda1b4a56a5e3d6ca75a0f650cb3ffb5fdfe/examples)查看；相关历史文档已链接到该版本。
